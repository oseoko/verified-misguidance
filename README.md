# CiteTrace

Code for **Verified Misguidance: Measuring Structural Citation Failures in
Search-Augmented LLMs**.

[Dataset](https://huggingface.co/datasets/oseoko/citetrace-vm)

## Reproduce the results

Python 3.12. The required data are bundled; no API keys are needed.

```bash
git clone https://github.com/oseoko/verified-misguidance.git
cd verified-misguidance
pip install -r requirements.txt
python -m src.analysis.reproduce \
    --input data/analysis_master.parquet \
    --output-dir results/d_tables \
    --with-validation
```

Generates 14 Appendix D tables and two Appendix C validation tables.
Use `--with-validation` for human-evaluation results. The pre-crawl bias
table and qualitative cases are not generated by this command.

## Repository

| Path | Contents |
|---|---|
| `data/` | Analysis data and human-evaluation tables |
| `src/analysis/` | Table reproduction and validation |
| `src/search/`, `src/judge/`, `src/citetrace/` | Collection, labeling, and scoring |
| `scoring_matrices/`, `schemas/` | Score lookups and field definitions |
| `scripts/`, `samples/` | Pipeline commands and sample queries |

The data cover 11,200 questions, ten models, and 761,495 citations.
Raw model responses are available in the Hugging Face dataset.

## Collect new data

Set provider API keys in `.env` using `.env.example`, then run:

```bash
python -m playwright install chromium
cp .env.example .env
# Fill in the API keys before running the pipeline.
bash scripts/pipeline.sh all sample
```

This runs the three-query sample using paid provider APIs. Set `QUERIES`
and `MODELS` to use other queries or models. Output is written to
`data/sample_run/sample/`.
